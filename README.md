# ZP Works Estimator releases

This repository holds only the released Windows packages of ZP Works Estimator, a works estimation application for Zilla Parishad and PWD offices. It contains no source code.

## Download

Open [Releases](https://github.com/abhishekdhumalwork/zp-work-estimator/releases) and take the latest version:

- `ZP_WorkEstimator_v<version>_Setup.exe` installs the application.
- `ZP_WorkEstimator_v<version>_Windows.zip` is the portable package, which the application's update check downloads.
- Each package has a `.sha256` file beside it. The application checks it before installing anything.

## Updates

An installed copy checks this page for a newer release and offers to download it. No GitHub account is needed.
